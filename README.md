# Kbh Sites | Modelo "A rua acesa"

Um dos três modelos da landing page da Kbh Sites. Conceito: uma rua de comércio à noite, onde quem tem página está com o letreiro aceso. A pessoa digita o nome do negócio e o letreiro dela acende.

Página estática, arquivo único (`index.html`). Exemplos em `exemplos/`, vídeos dos cases em `casos/`.
